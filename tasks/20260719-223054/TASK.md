# Spike: adversarial UX review of the agent page

- STATUS: CLOSED
- PRIORITY: 0
- TAGS: spike, agent, ui

## Goal

Honest, adversarial UX review of the agent page: what works, what is mediocre,
what is bad, would the target user be happy, and concrete prioritized
improvements. Deliverable is the review doc + seeded tasks.

## Outcome

RECOMMENDED. The surrounding chrome is genuinely good (rich context/quota/tool
info the official clients hide, coherent theme), but the core conversation loop
is where the pain is: no markdown/code rendering, a dead "..." on long turns, a
single-line composer, no copy/affordances, and an undifferentiated sidebar. A
technical user would be impressed by the instrument panel but frustrated chatting.

See tasks/20260719-223054/SPIKE.md. Seeded (prioritized): 20260719-223102
(markdown/code, P0), 20260719-223103 (turn progress/streaming, P0), 20260719-223105
(multi-line composer, P1), 20260719-223106 (sidebar grouping, P1), 20260719-223111
(chat affordances/polish, P2).
